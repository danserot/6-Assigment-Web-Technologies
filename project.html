jQuery quick guide

A selector finds elements on a page. For example, $('#title') finds the element whose ID is title.

It registers a function that runs when the user clicks the selected element.

.slideToggle() expands a hidden panel or collapses a visible one with a vertical animation.

.stop(true, true) clears queued effects so repeated clicks do not leave a long animation queue.

This project uses .on().slideUp().slideToggle() and updates aria-expanded.
